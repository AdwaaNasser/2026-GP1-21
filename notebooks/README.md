# Notebooks

The notebooks behind Bayyinah's burnout prediction model.

- `preprocessing.ipynb`: data exploration and preprocessing
- `regression_model.ipynb`: the regression model used in Bayyinah
- `classification_model.ipynb`: the classification models we compared it with
- `generalization_evaluation.ipynb`: testing the model on our survey of 52 employees

## Data

Download the dataset from [Kaggle](https://www.kaggle.com/datasets/mohankrishnathalla/mental-health-and-burnout-in-tech-workers-2026) and put `mental_health_burnout_tech_2026.csv` in this folder. The survey responses aren't included, to protect participants' privacy.
